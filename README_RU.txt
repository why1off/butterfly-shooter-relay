BUTTERFLY SHOOTER — СЕТЕВАЯ ИГРА ЧЕРЕЗ СЕРВЕР

Что изменено
- Убраны ручные SDP-коды и WebRTC.
- Один игрок создаёт комнату и получает код из 6 цифр.
- Второй вводит код и подключается.
- Все игровые сообщения идут через WebSocket-сервер (WSS/443 после публикации).
- TURN, STUN и настройка NAT не нужны.

ВАЖНО: сервер нужно один раз опубликовать в интернете. Я не могу разместить его в твоём аккаунте хостинга без доступа к нему. После публикации адрес сервера вставляется в HTML один раз.

КАК ЗАПУСТИТЬ СЕРВЕР (Render)
1. Распакуй архив.
2. Загрузи папку server в новый GitHub-репозиторий (можно загрузить файлы через сайт GitHub).
3. Открой https://render.com/ и войди через GitHub.
4. Нажми New → Blueprint, выбери свой репозиторий и подтверди создание сервиса butterfly-shooter-relay.
   Если Blueprint недоступен: New → Web Service, выбери репозиторий; Root Directory = server; Build Command = npm install; Start Command = npm start.
5. Дождись статуса Live. Render выдаст адрес вида https://butterfly-shooter-relay.onrender.com.
6. В файле butterfly-shooter.html найди строку:
   const NET_SERVER_URL = 'wss://SET-YOUR-SERVER-URL-HERE';
   Замени её на адрес своего сервиса, заменив https:// на wss://, например:
   const NET_SERVER_URL = 'wss://butterfly-shooter-relay.onrender.com';
7. Сохрани файл. Для игры открывай butterfly-shooter.html в браузере на обоих компьютерах.

КАК ИГРАТЬ
Хост: Сетевая игра → Я создаю игру → Создать комнату → отправить другу 6 цифр.
Друг: Сетевая игра → Я подключаюсь → ввести 6 цифр → Подключиться.
Хост нажимает «Начать бой».

ПРИМЕЧАНИЯ
- Бесплатный Render может «усыплять» сервис после периода бездействия. Первое подключение после сна может занять до минуты; подождите и попробуйте ещё раз.
- Если университет полностью блокирует WebSocket/WSS, потребуется разрешённый университетом хост/сеть. Не пытайтесь обходить правила сети.
- Для двух игроков сервер пересылает игровые сообщения через интернет; это не прямой P2P.
- Не публикуй приватные данные в комнатах: код комнаты временный, но это не система аккаунтов.
